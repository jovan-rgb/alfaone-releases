Cara install

  1. Download IPA lewat tombol di atas.
  2. Pasang Sideloadly (Windows/macOS) atau AltStore di komputer/iPhone.
  3. Hubungkan iPhone, login dengan Apple ID, pilih file IPA, lalu mulai proses signing & install.
  4. Di iPhone: Settings → General → VPN & Device Management → pilih developer Apple ID-mu → Trust.
  5. Buka aplikasi AlfaOne. Selesai.
Penting: file ini unsigned (belum ditandatangani), jadi tidak bisa dipasang langsung seperti aplikasi App Store. Kamu harus menandatanganinya dengan Apple ID sendiri. Apple ID gratis: aplikasi berlaku 7 hari dan perlu di-sign ulang. Apple Developer berbayar: 1 tahun.

Pertanyaan umum

Apakah ini dari App Store?

Tidak. Ini build internal (unsigned) yang didistribusikan untuk instalasi mandiri. Aplikasi tidak melalui review App Store.

Kenapa harus di-sign sendiri?

iOS hanya mau menjalankan aplikasi yang ditandatangani sertifikat Apple yang valid. Sideloadly/AltStore membuat tanda tangan sementara memakai Apple ID-mu, tanpa perlu akun developer berbayar.

Apa saja isi aplikasinya?

Menu intranet AlfaOne (APP INTRANET Original, Human Capital, RRAK, BST Online, KOPKAR, SO Karyawan, SO ATM/Tenant) yang dibuka di dalam WebView. Login, SSO, dan hak akses tetap mengikuti sistem resmi SAT.

Apakah notifikasi push dan absensi native tersedia?

Belum. Build ini membungkus situs intranet; fitur native seperti push notification, biometric login, dan bridge absensi belum diport. Halaman web yang meminta kamera/lokasi tetap bisa memakai izin iOS.

Kenapa build-nya unsigned?

Sertifikat distribusi Apple Developer tidak disertakan dalam repo publik. Build unsigned bisa diunduh siapa saja, lalu ditandatangani di perangkat masing-masing.
